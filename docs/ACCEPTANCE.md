# 开发顺序与验收门槛

## 公共大厅增量门槛

当前原生身份/名片/私聊基础已验证部分见 NATIVE.md。下列大厅能力已真实实现并验证，具体宿主范围见 NATIVE.md；不等于所有平台通过：

1. 无身份、零好友也能经明确同意连接并阅读真实大厅。
2. 首次发言才创建/解锁签名身份；返回先前草稿与回复对象，不自动发布完整名片。
3. 两端经本地真实中继发送、回查公开消息与引用；公开/私聊事实与状态分开。
4. 断线、重连、重复事件、长文本、恶意内容、发送节流、本地屏蔽、有界同步。
5. 大厅话题 → 查看发言者 → 发起私聊 → 对方同意 → 私人会话的原生完整流程。
6. 读旧消息时收到新消息不跳位置，窄窗口可滚动到底部和顶部，草稿不丢。
7. 公网写入已在明确授权后验证；不同物理网络和其他 Desktop 仍须单独验收。

## 初期设计包（历史阶段）

- 产品范围、信息架构、四页 UI、首次加入、连接异常、身份与隐私设计。
- 可点击的离线原型，深浅主题、系统主题响应和窄窗口。
- 原型浏览器回归、实际渲染截图。
- 不提供安装包；不把预览打开当成 DSH 集成或网络通过。

## 下一阶段：先处理会影响可行性的点

| 顺序 | 工作 | 通过证据 |
|---|---|---|
| 1 | 纯官方 DSH rc.5 空插件 | 不改官方文件，原生“搭子”入口打开面板；卸载入口消失；DSH 原生对话正常 |
| 2 | 宿主主题/面板尺寸 | DSH 设置切换浅深立即同步；压缩宿主面板，内容可读、可滚动、无竖字 |
| 3 | 安全身份与存储 | Host 密钥隔离；创建→备份→新测试配置导入→核对同一公钥；不在 UI/日志出现私钥 |
| 4 | 中继资格测试 | 每节点签名读写、回查、认证、接收能力结果；失败有原因，不只浏览首页 |
| 5 | 两端互发现 | 两个独立测试身份、不同网络、共同节点，加入后发现；关闭后租约失效；旧公告不复活 |
| 6 | 好友与私聊 | A 邀请→B 接受→A/B 双向加密消息；重启/重连历史和关系恢复 |
| 7 | 可恢复异常 | 节点部分故障、断网、退出重启、重复事件、历史损坏和版本不兼容 |
| 8 | 发布包 | `.tgz` 新配置安装，Windows/macOS 与 Web/Desktop 按实测记录兼容范围 |

测试数据全部合成。公开中继只在明确授权的验证任务中使用测试身份和最少事件，不发布个人真实名片；不调用付费模型。

## 正式发布必测

1. 官方 DSH 新配置和兼容 WorkDSH 新配置互联；不依赖 WorkDSH 企业登录、私有服务或平台重写。
2. 无密钥时正常引导；不能安全保存时停止并报具体原因。未备份不显示“已备份”。
3. 默认不发布名片/活动，开启时明确字段，关闭不续租，不能保证删除互联网副本。
4. 签名错误、冒充作者、过期/过远未来事件、未知协议、大消息、非法文本、重复事件均正确处理。
5. 缺少私信接收配置时不盲发。密文层身份不一致时拒收；对照 NIP 官方测试向量。
6. A 发邀请，B 接受；取消/过期/重复/交叉邀请幂等；非好友不会进入普通会话。
7. 发送前持久化；断网内容不丢；重试不重复；收到两次只显示一条；ACK 不显示已读。
8. 屏蔽后不再展示新增消息，解除后按用户操作恢复；对方不收到“被屏蔽”的系统通知。
9. 历史损坏不覆盖为空；身份/消息迁移可恢复；卸载不擅自清空用户数据。
10. 300px 插件容器、短高度、长昵称、公钥、千字消息、1000 个已缓存名片仍可操作。发现分页和滚动均有效。
11. 系统主题与 DSH 手动主题不同也以 DSH 为准；弹窗、按钮、输入框、焦点同步变化。
12. 不自动打开链接、远程图片、附件，不执行对方代码，不读取 DSH 会话/模型配置/用户文件。
13. 真实发布记录测试平台、版本、直连/代理、节点、结果和限制；未测试项不写“已支持”。
