# 产品与交互设计 · v0.1 草案

状态：设计供评审，2026-10-31。已实现离线交互原型，真实 DSH 与中继接入未实现。

## 定位

DSH 搭子是安装在官方 DSH 上的社区社交插件。帮助主动加入的人发现同好、发送邀请、成为好友并私聊。WorkDSH 用户与官方 DSH 用户使用同一协议，不按发行版隔离。

它不扫描别人电脑，不统计所有 DSH 用户，不读取工作区，不以模型账号或企业账号作为身份。列表只包含主动发布兼容名片的人；不能证明对方实际安装了哪个发行版。

## 首版边界

| 做什么 | 使用者得到什么 |
|---|---|
| 本地身份与加密备份/恢复 | 不依赖项目作者的账号服务器，身份可迁移 |
| 昵称、文字头像、最多三个兴趣、简介 | 能介绍自己和想交流的内容 |
| 选择加入发现 | 可以先浏览，再主动公开名片 |
| 有界发现列表、兴趣/关键词筛选、分页 | 人多时仍然可用，明确只代表已同步结果 |
| 好友邀请、接受、忽略、取消、过期 | 未同意前不混入正常聊天 |
| 好友文字私聊、失败重试、本地历史 | 能正常联系并看懂发送状态 |
| 停止公开、屏蔽、连接详情 | 可以退出发现并处理骚扰 |

首版不做广场动态、群聊、附件/语音/视频、自动共享会话文件、AI 代聊、自动执行对方发送的代码、地理位置匹配、付费会员。后续有需求再设计。

## 信息架构与入口

DSH 原生侧栏只注册一项“搭子”，打开插件主面板。四项子导航均在插件面板顶部一行展示：发现搭子 / 消息 / 好友 / 设置。不增加第二个内部侧栏、介绍区或宣传大标题。遵循宿主面板生命周期，卸载时注销入口、订阅和定时器。

消息页只承载人与人的聊天。用户自己的 AI 对话、模型选择、轨迹与授权留在 DSH 原生界面，不复制也不替换。

## 首次使用

1. 打开“搭子”，看到简介和“创建身份 / 导入已有身份”。
2. 新身份在 Host 本地生成；用口令加密导出备份，或明确“稍后备份”继续。未备份持续温和提示，不因跳过而宣称完成备份。
3. 昵称与简介先保存本地，展示“尚未公开”。不在打开插件时自动发名片或活跃公告。
4. 选择候选中继。说明浏览也会向中继暴露连接信息；有认证要求时不能未经同意自动签署身份认证。
5. 用户点击“开启被发现”，列出公开字段与保留限制，再确认发布。名片至少被一个合格节点确认接收后显示“已发布”；失败保留本地资料，可重试。
6. 逐项提示“连接 / 名片发布 / 活跃发布 / 私信接收准备”结果。连接成功不代表能被发现或能收私信。

原型中的“首次使用流程”只说明上述设计，不生成密钥、不下载虚假备份。

## 发现与在线

- 名片内容：昵称、文字头像、简介、兴趣、想交流的事情、粗粒度近期活动。
- 初始每页 6 位，正式版按容器宽度调整；独立分页与可滚动内容区必须同时成立。
- 关键词/兴趣变化回到第一页；删除/屏蔽或刷新结果使当前页越界时回退到有效页。
- 正式版文案是“已同步 N 位”，不宣称全网总人数。按活跃租约排序，未知/过期不画在线绿点。
- 所谓“近期在线”仅表示插件最近发过有效活动事件。不是读屏状态、真人在线保证或对方正在看聊天。
- 关闭被发现后停止续租并发布停止声明；其他节点缓存可在租约到期后清除。不能保证互联网副本删除。

## 好友与邀请

查看名片 → 核对公钥 → 写一句介绍 → 发邀请 → 等待接受 → 好友 → 私聊。

- 邀请通过加密控制消息发送；不是广播一条带双方身份的公开好友关系。
- 同一邀请有唯一 ID，去重、有效期与取消状态。双方同时邀请按公钥对合并。
- 接受消息指向确切请求与修订；未成功到中继时显示“接受待同步”，重试不能新建一条关系。
- 对方未配置可用私信接收中继时显示“对方尚未准备好接收邀请”，允许稍后重试。
- 陌生人只进入邀请收件箱，客户端限流并限制大小；非好友文本不混入好友消息。
- 忽略不向对方发送负面通知；屏蔽是本地策略，不承诺阻止对方在其他客户端发信。
- 通过密钥验证的是签名归属，不是昵称对应的现实身份，也不是 DSH 官方认证。

## 消息与恢复

| 用户看到的状态 | 何时才能显示 |
|---|---|
| 草稿 | 尚未提交，按会话保留 |
| 正在发送 | Host 已持久保存待发记录并尝试发布 |
| 已到中继 | 至少一个收件方指定中继明确接受加密包；不是对方已收到/已读 |
| 发送失败 | 可重试错误；保留内容和原因 |
| 暂不可发送 | 收件方无有效接收配置、关系未确认或已屏蔽 |

首版不做“已读”回执。断网不清空输入；点击重试沿用消息 ID、收件人和待发记录。Host 重启恢复队列并去重；多中继/重复推送只显示一次。历史读取失败有恢复提示，不能悄悄生成空库覆盖。

Enter 发送、Shift+Enter 换行，中文输入法组合期间 Enter 不发送。消息为纯文本，链接不自动预览，不渲染来自对方的 HTML，不触发 AI 工具。

## 用户控制与异常

- 关闭发现 / 全部中继不可用 / 身份存储不可解锁 / 无可用私信中继 / 版本不兼容分别展示具体原因与对应动作。
- 中继部分故障可继续使用其他已验证节点，显示连接详情，不能把“失败一个”当成“全部断开”。
- 私聊本地历史与身份的备份范围分别说明；恢复身份不保证能从公共中继找回全部历史。
- 删除本地聊天、移除身份、退出发现区分处理；删除身份前说明备份后果并确认。
- 第三方名片和消息都是不可信内容；不自动打开远程图片、下载文件或提交链接。

## 原型与正式能力的区别

已做的交互：发现筛选分页、演示名片、发布确认、演示邀请/接受、聊天草稿、失败重试、屏蔽、主题与窄屏。

未做：真实身份创建/备份、真实连接、签名验证、加密、邀请同步、真实状态、历史持久化、DSH 挂载与安装包。界面中的所有网络结果都显式带“演示/模拟”。
