# Slack 风格原型调研（2026-10-31）

用户要求先做原型，并参考 Slack 页面风格。本次不安装第三方插件，不修改已安装的 DSH / WorkDSH。

## 核对的一手来源

- https://github.com/LeoAndJellyfish/DeepSeek-Harness-Threads ：README 展示可选 Slack 风格消息行、日期分隔、悬停操作、回复计数、右侧线程及持久草稿。其线程是 DSH AI 会话的 fork，不能当成人际公共聊天的现成协议层；未实装或审计该项目。
- https://github.com/STARDUSTLC666/dsh-slack ：连接 Slack App 的通知、Socket Mode 收件箱、线程回复工具，不提供独立人际聊天室。
- https://github.com/force-push/dsh-slack-channel ：将真实 Slack 频道映射为 DSH Agent 会话，仍依赖 Slack 工作空间。
- https://slack.com/help/articles/212596808-Adjust-your-sidebar-preferences ：导航区与频道、私信分组。
- https://slack.com/help/articles/115000769927-Use-threads-to-organize-discussions- ：对某一条消息展开话题，避免频道刷屏。

检索范围内未找到能直接替代 DSH 搭子公网人际聊天的完整 Slack 式插件；这是本次检索结果，不是生态不存在此类项目的断言。

## 原型范围

`design/` 使用紫色导航、浅色频道栏、头像/作者/时间消息行、日期分隔、回复计数和右侧话题面板。三条频道为明确标示的离线示例；可以切换、各自保留草稿，话题内回复不会作为新独立消息挤入频道主流。频道成员为演示名单，不伪装实时在线。窄屏切换频道及话题返回可操作。按用户最新要求，原型使用固定经典 Slack 配色，不随系统深浅色变化：顶栏 #350d36、侧栏 #3f0e40、频道选中 #116b63、白色消息区。外侧竖向导航、顶部本地频道搜索、头像作者时间及右侧话题形成完整框架。

仅本地内存交互，刷新会清除演示消息；CSP 禁止网络通信。真实插件维持上一轮版本。尚未接入多频道、线程的公网路由与持久化；界面交互不能当作这些能力已经交付。

验证：原型既有 13 项检查通过；另在可见预览中验证话题内回复使计数增加、频道主消息不增加，以及频道切换后未发送草稿恢复。所有验证消息仅留在内存，未连接中继。

按用户提供截图进一步调整：顶栏深紫 #350448，侧栏由 #481961 经 #54216b 过渡到暖紫 #753477，选中频道 #2476bb，白色圆角内容面板。配色固定，不受系统主题影响。13 项原型检查通过，截图为 `images/slack-gradient-prototype.png`。

聊天区进一步统一：头像/作者/时间对齐，连续作者消息紧凑显示，重复引用正文改为可点击 @昵称入口，话题统计下置；输入区增加格式标记、表情和成员操作，频道正文与右侧话题采用同一字重与行距。格式按钮仅插入 Markdown 标记，原型不承诺完整富文本渲染。

输入区改为一体式紧凑布局：左侧加号展开格式/表情工具，中间输入文字，右侧图标发送；空文本禁用且灰色，输入后启用。话题输入框同步圆角、边框与图标发送。仍只是离线原型，不提供附件上传。

头像按红框反馈改为本地原创插画，不再显示单字占位块。频道消息、话题、成员名单和个人入口共用同一套头像，聊天中为 36px（窄屏 32px）并统一圆角及对齐。人物仅为合成原型形象，不是实际用户头像；SVG 随原型提供，不请求第三方头像服务。

全页面一致性修复：主内容区统一不透明白色底，紫色渐变仅作为外壳与频道导航；消息空状态、零联系人、个人资料、隐私和发现页统一布局。私聊沿用头像/作者/时间消息行和紧凑输入框；顶部搜索按页面作用于频道、私聊、联系人或发现，个人设置隐藏搜索。新增四页面白底/文字可读性和窄屏回归，合计 14 项通过；本轮仍不更新已安装桌面插件。

全局样式收敛到 `design/ui-system.css`：操作蓝、导航紫色渐变、白/浅灰紫背景、统一文字/边框/危险语义、按钮层级与交互状态。历史样式里的操作色已改用这些变量。输入框、开关、分页、选中会话、链接及弹窗共用规范。样式示例见 `design/style-guide.html`；原型检查核对跨页面主按钮实际渲染颜色及空内容发送禁用。

最新用户反馈：亮蓝与紫色外壳不协调。全局操作色改为柔和紫 #75408d，悬停 #623176，浅紫底 #f3edf7；频道选中使用白色半透明叠层，替代蓝条。按钮、文字操作、提及、焦点、开关和分页均跟随同一变量。此规则替代此前的蓝色方案。
