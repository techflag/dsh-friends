# UI 与宿主集成规范

状态：公共大厅已真实接入。用户反馈日志式列表不友好后，已在真实插件改为左右气泡、就近回复、紧凑引用与输入区；原生深浅主题、窄窗口和新消息滚动已验收。

## 方向

紧凑、直接的工具型界面。浅色预览采用白底、少量绿色重点色，深色保留足够文字对比。头像用文字和少量柔和底色，避免伪造真人照片或加载第三方追踪图片。正文采用可读的中文系统字体。不使用宣传大标题、英文装饰、右侧介绍卡片或重复内部侧栏。

这是插件 UI，不设计新的客户端外壳。预览顶部的“DSH 插件设计预览”和主题选择器仅为评审工具，正式插件不出现。四项插件内部导航放在一行顶部标签中，不在 DSH 原生侧栏旁再放一个侧栏；外层 DSH 的全局侧栏、AI 对话、任务浏览器由宿主管理。

## 四个页面

| 页面 | 主体 | 常驻操作 |
|---|---|---|
| 大厅（默认） | 公共聊天流、引用回复；消息区独立滚动 | 底部公开发言、点击昵称看人 |
| 消息 | 会话列表 + 私聊线程 | 头部名片入口、底部发送区 |
| 联系人 | 待处理私聊申请 + 已建立联系的人 | 接受/忽略、继续聊、可选发现名片 |
| 我 | 名片、可见性、屏蔽列表、连接、身份备份 | 保存资料、可恢复错误操作 |

大厅以一个公共聊天区为起点，不铺人物卡片。本人消息靠右，其他人靠左；宽屏气泡宽度受限，回复操作在气泡旁悬停/键盘焦点时出现，触控窄屏常显。引用最多显示两行，正文与引用分别处理。正常发送状态弱化，“已发出”解释在提示中；失败突出重试。发送区固定在聊天流底部，公开/私聊有文字区分。引用在当前列表中呈现，不新开第三列。初次只读不因没有好友或身份而拦住；首次发言才引导昵称和本地身份。

同好发现列表保留为联系人页的次级入口，仍有筛选、分页和滚动。

## 主题

原型用 CSS 语义变量实现 light/dark/system，并通过 `prefers-color-scheme` 响应系统变化。

正式 Client 优先使用官方 `dsh-client-ui-primitives` 和宿主 `--dsw-*` 语义 token。已在 rc.5 发布包核对：按钮使用 `--dsw-alias-button-primary-fill` / `--dsw-alias-label-primary-foreground`，文字使用 `--dsw-alias-label-primary`，表单背景使用 `--dsw-alias-bg-layer-1`。需要程序化主题状态时使用 `dsh-client-ui-theme/client` 的 `ctx.theme.getTheme()` 与 `theme/change`，不是猜测一个 `useTheme` Hook。跟随 DSH 内设置，不能只跟操作系统或 DOM 的猜测 class。UI 组件、表单、弹窗和焦点必须一并适配，避免深色页面出现硬编码白按钮。

不向宿主 `body` 写主题 class，不全局覆盖 button/input；正式样式限制在 `.dsh-friends` 根下。品牌绿仅作次要标识，主要按钮/文字/背景以宿主主题和对比为准。正式接入前核对当前 SDK 导出的主题 API，见技术方案。

## 尺寸与滚动

- 正式面板以可用容器尺寸为准，使用 container queries/ResizeObserver，不以整个宿主窗口宽度误判插件可用空间。
- 宽布局：插件顶部标签约 56px 高，发现按紧凑行展示（约 90px/人），不再加内部侧栏和辅助区。
- 中等布局：保留顶部标签，名片简介和标签换行，正文始终 `min-width: 0`。
- 窄布局：顶部标签约 49px 高，隐藏重复文字操作；名片自然换行；消息列表与线程一次显示一个，有明确返回按钮，不把主内容挤成竖字。
- 外壳 `min-height: 0`、主区可滚动。不能只加分页而保留被裁切的高度。
- 大厅消息区独立滚动，发送区常驻；联系人/我/发现采用一个主内容滚动区。消息列表、线程分别滚动，发送区不随消息滚走。
- 固定导航和发送区不盖住内容；所有内容可用鼠标滚轮、触控板和键盘抵达。
- 初始每页 6 位，搜索/兴趣变化归第一页，屏蔽后修正越界页；列表总数是本地已同步集合。

原型的 viewport media queries 仅用于独立预览，接入 DSH 时必须改为面板容器断点。

## 操作与状态

- 每行只突出一个主操作：陌生人“发起私聊”，已有联系人“聊一聊”，已申请“已发出邀请”。大厅每条发言的主操作是“回复”，查看昵称后才出现私聊入口。昵称打开详情。长简介、公钥等详细信息放名片弹窗，列表突出昵称、兴趣和可用操作。
- 设置可见性开启前弹出公开字段确认，取消保持关闭；关闭停止发布但明确缓存保留。
- 邀请、发送、发布资料显示处理中/成功事实/失败原因，不能只弹一条通用 toast。
- 原型选择“断开（模拟）”后，可看失败与重试；正式版由 Host 真实回执驱动。
- 更多操作放名片详情/设置，不在视口边缘展开会被裁切的小菜单。
- 复杂编辑用主页面，简短确认用原生模态对话框。对话框有最大高度及内部滚动、Escape 关闭、焦点约束/恢复。
- 空列表、无搜索结果、连接未建立、无好友、未公开、被屏蔽必须有不同文案与恢复动作。

## 可访问性

- 按钮有文本或可读名称，导航有当前页语义，分页有 `aria-current`。
- 颜色不是唯一提示；在线/异常同时给出文字。
- 搜索有 label；动态提示用 live region；键盘焦点清楚。
- 手机尺寸重要按钮点击区域正式实现不小于 44px。原型发现卡片桌面紧凑按钮接入触控尺寸需同步放大。
- 正文和界面文字对比目标 WCAG AA。不能以肉眼“看起来差不多”代替宿主双色实测。
- 长昵称/长公钥/长消息不横向撑破；输入法 Enter 不误发；减少动态效果设置生效。

## 自动头像（2026-10-31）

原生大厅、私聊、联系人、发现名片和当前身份入口统一使用本地几何头像。同一完整公开身份标识生成稳定的对称图案和协调底色；不依赖昵称、房间或随机数。未创建身份时显示中性占位图，不制造临时发言身份。头像不是身份认证凭证，仍需通过公钥核对身份。

生成器 `src/avatar-pattern.ts` 只输出固定 SVG 图形与预设颜色，不插入用户文本，不读取私钥，不加载第三方图片，不要求上传或新增头像存储。图形转换仅用于外观，不承担密码学功能。昵称旁的头像是装饰元素，避免读屏重复朗读。原型使用同一生成器为明确标记的合成身份生成本地 SVG，不再使用人物脸。未来换头像另行迭代。

头像第二轮改为大轮廓符号（环、叶片、山峰、波浪等），替换小尺寸难辨的点阵；保留完整公开身份决定外观的规则。昵称提升为 13px、深色、650 字重，时间仍次要；不放大正文或增加消息留白。原型和原生实现同步。

## 整体上下布局与免口令入口（最新）

原型及原生均采用顶部导航/默认房间标签，下方完整聊天流与底部固定输入区。取消插件内部两层左栏；同一插件内所有页面采用统一紫色动作、灰紫边界和明确的默认/禁用/焦点样式。主导航为社区、私信、联系人、我。

公开历史、设置和联系人入口不再强制跳到身份表单。新 Mac 用户首次发言自动准备本机身份，不出现注册、口令确认和私钥管理表单；旧版受保护身份只在明确选择高级恢复时显示原恢复界面。锁定的旧联系人/私聊显示“尚未读取”而非冒充空数据。历史查询使用独立加载状态，避免把发言按钮长时间显示为“处理中”。
