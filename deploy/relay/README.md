# DSH 搭子：实时中继与公开运营看板

该服务使用 `fiatjaf.com/nostr/khatru`，具体依赖固定在 go.mod / go.sum；它提供 Nostr 协议、事件验签、订阅转发和 NIP-42。本目录只增加接入策略、运营统计和公开页面，不实现私钥签名或自制密码算法。

## 数据边界

- **聊天不落盘**：公开消息 kind 9 仅在内存缓存每个房间最近100条，最多24小时，重启清空。加密私聊信封 kind 1059 仅实时转发，不进入缓存。两者都不写文件、不记正文日志。
- **持久保留运营统计**：累计身份数、每日活跃、公开消息计数、各房间分布，以及用于去重的 HMAC 标识。每日明细保留最近 400 天，累计值保留；公开接口不返回标识列表。
- **短时路由缓存**：公开收件地址 kind 10050 和自愿公开的名片 kind 30388 只留在有上限、自动清理的内存缓存；不持久化这些事件。
- 新进入大厅的用户可读取近期缓存；离线后只能补看仍在缓存范围内的公开消息，私聊不补发。用户设备可以保存已经收到的消息；“中继不落盘”不等于其他参与者不能保存。
- 用户数依据签名验证的身份计算，不是实名人数。浏览网页不会增加用户数；连接数不是在线人数。近期消息重试通过有界事件标识集合去重，不承诺无限期防重放统计。
- 公开网页和 `/api/stats` 只读，无管理修改、名单查询或导出聊天内容的接口。

## 本地验证与构建

需要 Go 1.26（可用官方 Go 容器）。

```sh
go test -race ./...
CGO_ENABLED=0 GOOS=linux GOARCH=amd64 go build -trimpath -o relay .
```

运行参数：

- `DSH_RELAY_STATE`：运营统计目录，要求仅服务账户可读写。
- `DSH_RELAY_LISTEN`：默认 `127.0.0.1:17777`；公网通过反向代理提供 TLS。
- `DSH_RECEPTION_API_KEY`：接待助手使用的服务端 DeepSeek Key；未设置时 AI 接话关闭，公共聊天照常工作。也兼容 `DEEPSEEK_API_KEY`。
- `DSH_RECEPTION_API_URL`：默认 `https://api.deepseek.com/chat/completions`。
- `DSH_RECEPTION_MODEL`：默认 `deepseek-flash`。
- 当前公开域名为 `relay.techflag.cn`，框架服务 URL 与页面连接地址需同时保持一致。

API Key 只能由受限的服务配置注入，不写入 systemd 单元正文、仓库、插件包、日志或统计备份。接待助手只接收触发它的公开发言；不读取私聊、DSH 会话或工作区。进房心跳和在线快照是短时内存状态，不持久化用户列表。

隐私用例检查正文、信封、原始公钥与事件 ID 不进入统计文件；重启后计数保留；新用户可读取100条/24小时范围内的公开缓存，重启后公开缓存清空，私聊历史查询始终为空；损坏的计数数据不会被静默清空。

`tests/selfhosted-relay.ts` 是明确授权后才运行的公网部署验收，不属于默认测试或 CI。它只写合成测试数据，并且应使用隔离的统计目录。Windows 实机和不同客户端网络仍需另行验收。

## 运行与维护

实际部署使用独立低权限服务账户、只监听回环地址、受限的 systemd 服务和 Nginx 子域名。保留原网站默认路由。TLS 由单独的 ACME 工具维护，证书自动续期；运营统计及统计去重密钥每天备份、保留 7 天。备份不含聊天数据。

- 服务：`dsh-friends-relay.service`
- 续期：`dsh-friends-cert-renew.timer`
- 备份：`dsh-friends-operations-backup.timer`
- 部署基目录：`/opt/dsh-friends-relay`
- 运营数据：该目录下的 `jail/state`；不要公开该目录或备份，里面包含内部去重标识和统计密钥。
- 中继域名关闭 HTTP 访问日志；协议框架的正文相关日志不启用。现有其他网站日志配置不改动。
- 安装凭据、TLS 私钥、统计密钥、实际服务器备份均不进入仓库或插件包。

升级时先验证新二进制，备份运营数据，原子替换二进制后重启服务；不要将运行时计数目录当成可删除的缓存。用户主动要求删除运营数据时才清空。
